# Contributing

Thanks for wanting to help with Conker's Bad Fur Day: Reloaded! Bug fixes, new options, controller layouts,
translations and docs are all welcome.

## Good places to start

- Issues labelled [good first issue](https://github.com/DahSidiAbdallah/ConkerBFDReloaded/labels/good%20first%20issue)
  or [help wanted](https://github.com/DahSidiAbdallah/ConkerBFDReloaded/labels/help%20wanted).
- Anything you hit yourself while playing: open an issue first if it's a big change, so we can agree on it.

## Building

See [Building](README.md#building) in the README. You need your own US ROM of the game.

## What we're going for

- **Faithful first.** The game should look and play like the N64 original unless a setting says otherwise.
  Widescreen fixes move the camera rather than adding black bars, and textures keep the original colours.
- **New behaviour goes behind a setting** (Classic keeps the original), with a short, plain description.
- **Test single player** as well as what you changed, especially for camera, input and rendering changes.
- **Small, focused pull requests** are easier to review and merge.

## Pull requests

- Say what you changed, why, and how you tested it (Windows, Linux, Steam Deck...).
- If it fixes an issue, write its number (`fixes #45`) in the description and in the commit message.
- Keep commit messages short and to the point.
- Never include ROMs, ROM dumps or other copyrighted game files, and don't link ROM download sites.
  Textures or sounds from other projects need their licence and credit.

## Talking
